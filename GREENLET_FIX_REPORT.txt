ATS-SMC v48 GREENLET/PERSISTENCE FIX
========================================

ROOT CAUSE:
  greenlet 3.5.4 was installed with a broken/incompatible DLL for
  Python 3.13 on Windows x64. The _greenlet.pyd extension module
  failed to load at import time:
    "DLL load failed while importing _greenlet: Не найден указанный модуль"

  SQLAlchemy 2.x uses greenlet internally for its async engine
  (asyncpg driver). Every async DB operation (session.get, session.execute,
  session.commit) triggers greenlet import. When greenlet DLL is broken,
  ALL async database persistence fails - including order_manager._persist_order().

  The fix: reinstall greenlet to pull the correct prebuilt wheel
  (cp313-cp313-win_amd64.whl) for Python 3.13 on Windows.
  pip downloaded greenlet 3.5.5 with the correct binary wheel.

  No code changes were required. The project's async DB code is correct.

GREENLET VERSION:
  Before: 3.5.4 (broken DLL)
  After:  3.5.5 (correct cp313-cp313-win_amd64.whl)
